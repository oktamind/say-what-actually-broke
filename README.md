One line of software error copy that tells the user the brutal truth about what went wrong — a save failed because the disk is full — and makes them laugh on the way: the document now lives only in memory, so free some space before it forgets itself.

## Run it

```sh
node main.ts
```

The program writes the single-line error message to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
